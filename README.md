# What's New

Welcome to the Mobiloan What's New space. Every Mobiloan release is documented here, grouped by **minor version** and organized into **version families** for easy browsing.

👉 **Jump straight to the latest release:** [4.84 Release notes](app-version-4.8/4.84.md)

## How release notes are organized

* Each **minor version** gets its own dedicated page (e.g. `4.84`, `4.83`, `4.82`).
* **Patch releases** under a minor version (e.g. `4.84.10`, `4.84.00`) are listed on that minor version’s page, newest patch first.
* Minor versions are grouped by their **version family** in the sidebar (`App Version 4.8`, `App Version 4.7`, etc.), with the most recent family shown first.

Every patch on a minor version page is broken down into one or more of four change categories:

* 🚀 **New Features** – brand-new capabilities
* 🔧 **Improvements** – enhancements to existing functionality
* 🐛 **Bug Fixes** – defect resolutions
* 🎨 **Cosmetic Updates** – visual and UX polish
