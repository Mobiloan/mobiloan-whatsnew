# 4.76.00 - Email Notification Routing in Company Setup

## 🚀 New Features

### 4.76.00 - Email Notification Routing in Company Setup

#### Release Date: 05/05/2025

You can now configure **company-specific email notifications** directly within the **Company Setup module**. Now, each company can have **unique email addresses** assigned for specific notification types.

To get started, simply:

1. Select the desired company from the **Company Setup** section.
2. Navigate to the **Email** tab.
3. Enter the corresponding email address(es) for each notification type.

* Email addresses should be comma-separated if multiple addresses are required. All entered addresses will be added to the CC field of the email.

<figure><img src="../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure>

This enhancement works in conjunction with the existing **branch-level email routing**, giving you full flexibility to route notifications to both **company and branch level email addresses**.

### 4.76.01 - Client’s Maximum Total Outstanding Loan Balance

#### Release Date: 05/05/2025

We've improved our Evaluation Workflow with a new role-based threshold that automatically checks a client's **total active loan balance**. If the balance goes over a set limit, the loan can only be approved by another user whose role allows them to evaluate loans at that level or higher.

The maximum outstanding client balance threshold can be found under the **"Specific Evaluation Limitations"** section within the **Evaluation** tab.
