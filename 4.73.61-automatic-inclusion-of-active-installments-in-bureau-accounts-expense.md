# 4.73.61 - Automatic Inclusion of Active Installments in Bureau Accounts Expense

We’ve introduced a new **Category setting** that automatically includes any active installments in the **Bureau Accounts Expense** calculation.

**Why This Matters?**&#x20;

Previously, some loans failed to reflect up-to-date installments, leading to disputes and inaccurate affordability assessments. With this new setting, **Mobiloan** ensures that all **active installments** within the system are considered—eliminating errors and reducing the need for manual adjustments.

**How It Works**

* If a client has an **active previous installment** and takes a **top-up loan**, Mobiloan will automatically factor in the existing installment when assessing affordability.
* This is particularly useful if a **recent credit check** has already been performed, and you don’t want to create a **new bureau inquiry**.
* The system pulls the **most recent installment data** directly from the **Client Ledger** and integrates it into the **Bureau Accounts** field.

**How to Enable This Setting**

1. Navigate to **Setup Menu > Category > Affordability Tab**.
2. Enable the checkbox for **"Auto-Include Active Installments"**.
