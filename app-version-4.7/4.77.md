## 4.77.15 – New Category Setup Item

_Released: 2025-05-14_

### 🚀 New Features

**AVS-R Requirement and Collection Exception Period**

When the AVS-R (Account Verification Service - Real-time) rule is set to "Required once per bank account or any dormant loan," a new collection exception period must be established.

<figure><img src="../.gitbook/assets/image (480).png" alt=""><figcaption></figcaption></figure>

When this option is selected for the given **category,** Mobiloan checks if a successful collection has occurred on the same bank account within the specified timeframe. If such a collection is found, the AVS-R verification is not required again.

<figure><img src="../.gitbook/assets/image (481).png" alt=""><figcaption></figcaption></figure>

## 4.77.10 – New Automated Client Hold Statuses

_Released: 2025-05-13_

### 🚀 New Features

Two new system-generated client hold statuses have been introduced to support automated **Handover** and **Write-off** actions, while preserving any existing manually applied hold statuses:

* **System Auto Hold** – Automatically applied by the system when a hold is required during automated processes.
* **System Auto Write-off** – Applied when a loan is flagged for automatic write-off

To activate or modify a client with an existing **System Hold Status**, the user’s role must have the appropriate **Maintenance Rights** enabled.
