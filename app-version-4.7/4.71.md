## 4.71.03 – Additional Login Security Features

_Released: 2024-04-06_

### 🚀 New Features

#### Mobiloan strengthens login security with SurePhrase!

**What is SurePhrase?**

SurePhrase adds an extra layer of security to your Mobiloan account. When logging in, you'll be prompted to enter 3 random digits from your secure phrase key, along with your username and password. This key is set up on your Mobiloan profile and helps prevent unauthorized access even if someone knows your login credentials.

**How to enable SurePhrase Login Authentication:**

1. Go to **Setup > Role** and select the role you want to enable SurePhrase for.
2. In the workflow, enable the **SurePhrase Required** toggle.

<div align="left"><figure><img src="../.gitbook/assets/image (51).png" alt="" width="221"><figcaption><p>Toggle Feature to <code>Enabled</code></p></figcaption></figure></div>

**Learn More:**&#x20;

{% embed url="https://docs.mobiloan.io/features-and-automation/login-security-features/surephrase-login-authentication" %}

#### Control access with Authorized Login Devices

**What are Authorized Login Devices?**

With Authorized Login Devices, you can specify trusted devices for each user based on their role. This prevents users from logging in with unauthorized devices. Even if someone tries to log in from an unauthorized device, they'll need a one-time passcode (OTP) sent to their registered phone number to gain access.

**How to enable Authorized Login Devices per user:**

1. Go to **Setup > Role** and select the role you want to enable this feature for.
2. In the workflow, enable the **Device Authorization** toggle.

<div align="left"><figure><img src="../.gitbook/assets/image (52).png" alt="" width="214"><figcaption><p>Toggle Feature to <code>Enabled</code></p></figcaption></figure></div>

**Learn More :**&#x20;

## 4.71.01 – Future Payout Date

_Released: 2024-05-29_

### 🚀 New Features

This feature lets you create loans for clients where **the payout is scheduled for a future date.**&#x20;

This is ideal for situations where clients visit your branch and want their loan amount automatically deposited on a specific date.

The loan creation process remains the same - you can still generate and authorize the promissory note.

#### **Here's what's new**

* **Scheduled Payout Tracking:** We've implemented a daily scheduler that monitors these future payout loans.
* **Aligned Installment Date:** The system automatically aligns the first installment date with the chosen payout date.
* **Automatic Approval on Payout Day:** On the scheduled payout date, the loan is automatically set to "Approved" and appears in the "Evaluate Now" section of your active loans.
* **Improved Visibility:** Easily track upcoming loan payouts with the "Evaluate Now" notification.

#### Enabling the Feature

**Make sure the user creating the loan has the necessary Role Right enabled.** Please refer to the screenshot below for details on the specific Role Right required for this functionality.

<div align="left"><figure><img src="../.gitbook/assets/image (53).png" alt="" width="318"><figcaption><p>Origination Rights - Role Setup</p></figcaption></figure></div>

**For more information on configuring `Origination Rights` in Mobiloan, select the link below**&#x20;

{% embed url="https://docs.mobiloan.io/application/setup/role-right/origination-rights" %}

#### **Scheduling Loan Payout Dates**

Within the loan origination workflow, specifically during the "Product Selection" step, you can easily schedule a future payout date for your client's loan. Here's how:

1. Navigate to the "Product Selection" stage of the loan origination process.
2. Locate the field labeled "Loan Payout Date" or similar wording.
3. Simply choose your desired future date from the calendar pop-up or date picker provided.

**This will trigger the following automated features:**

* **Scheduled Payout Tracking:** Mobiloan incorporates a daily scheduler that monitors these future payout loans.
* **Aligned Installment Date:** The first installment date will be automatically adjusted to align with the chosen payout date.
* **Automatic Approval on Payout Day:** On the scheduled payout date, the loan is automatically set to `Approved` and appears in the `Evaluate Now` section of your active loans.

<div align="left"><figure><img src="../.gitbook/assets/image (54).png" alt="" width="375"><figcaption><p>Origination -> Product Step</p></figcaption></figure></div>

<div align="left"><figure><img src="../.gitbook/assets/image (55).png" alt="" width="375"><figcaption><p><code>Payout Future Button</code>> Payout Workflow </p></figcaption></figure></div>

#### Additional Functionality - Automatic Loan Expiry&#x20;

We've introduced a new feature to streamline loan application management. This allows you to configure an **automatic expiration period** for incomplete loan applications.

**Here's how it works:**

* You can define the number of days after which an unfinished loan application will **automatically expire.**
* Once expired, the application will no longer appear in the "**Active Loans"** section.
* An automated **email notification** will be sent to the branch informing them of the expired application.
