# 4.78 Release notes

## 4.78.06 – Password Security Enhancements

_Released: 2025-05-27_

### 🔧 Improvements

Users will no longer see their current password displayed in the user menu after logging in. To update a password, users must now enter their current password, adding an extra layer of protection. Similarly, updating a SurePhrase now requires entering the current SurePhrase to ensure secure changes.

***

## 4.78.05 – Improved What's New Template

_Released: 2025-05-27_

### 🔧 Improvements

* **New Template Structure**\
  Each _Major_ and _Minor_ update will now get its **own dedicated What's New page**.\
  &#xNAN;_&#x50;atch_ updates will be added to the existing page until the next Major or Minor release.
* **Clearer Categorization**\
  All updates will be grouped into four simple sections:
  * 🚀 **New Features**
  * 🔧 **Improvements**
  * 🐛 **Bug Fixes**
  * 🎨 **Cosmetic Updates**
* **Streamlined In-App Updates**\
  In-app What's New messages in **Mobiloan** will now only show **🚀 New Features**.\
  This ensures users only see the most relevant and impactful updates directly in the app.

This new format will make it easier to keep track of important changes while keeping in-app updates focused and clutter-free.

***

## 4.78.04 – FIC KYC Amendments

_Released: 2025-05-26_

### 🐛 Bug Fixes

Cases that skip evaluation will now correctly show as **High Risk** instead of **Management Signoff Required**. For Premium and Standard Enquiries, the **Enquiry Reference** is now visible in both the results and the PDF.

***

## 4.78.03 – Improved Messaging for SACRRA Resubmissions

_Released: 2025-05-22_

### 🎨 Cosmetic Updates

The system now provides clearer messages when resubmitting loans to SACRRA. The confirmation dialog and success message now specify whether the loan will be included in the **daily** or **monthly** file, based on its status.

***

## 4.78.02 – Improved Handling of Presentments in Payment Reconciliation

_Released: 2025-05-20_

### 🔧 Improvements

A change was applied to improve how **failed and successful presentments** are merged during payment reconciliation. The system now more accurately detects and combines related records, ensuring that financial data presented during reconciliation is correct and avoids duplicate entries.

This enhancement increases the reliability of recon reports and makes it easier for users to review accurate transaction results in the interface.

***

## 4.78.01 – UnitySure Monthly Insurance Report Generation

_Released: 2025-05-20_

### 🐛 Bug Fixes

The UnitySure monthly insurance report has been fixed to ensure both **Credit Life** and **Voluntary Life** policies are now correctly scheduled and included. This resolves previous issues where only one type may have been processed, ensuring complete and accurate monthly reporting for UnitySure clients.

***

## 4.78.00 – New Affordability Assessment Tool

_Released: 2025-05-16_

### 🚀 New Features

#### Affordability Assessment&#x20;

A new **"Affordability Assessment"** option has been added to the **Tools** menu. This feature lets users run a standalone affordability check for an existing client—without initiating a new loan application or triggering a new credit enquiry. It's especially useful for evaluating if a client can afford their next loan.
