# 4.74.1 - Variable Amplifin Promissory Note Client Fee Percentage

Please note that the ability to set a default **ALLPS Client Fee Percentage** in the **Repayment Method Setup** has been removed.

Instead, you can now declare the **Amplifin Promissory Note Client Fee Percentage** directly during the **Loan Origination Step**, providing greater flexibility and transparency in managing client fees.
