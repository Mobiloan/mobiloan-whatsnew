# 4.73.10 - Addititonal Client Hold Statuses

We’ve introduced **5 new client statuses** that users can now manually assign to clients.&#x20;

This update provides greater flexibility in managing client information, making it easier to filter reports based on specific statuses.&#x20;

Specifically, these new statuses allow users to flag clients with the corresponding  **credit report warning**, helping to highlight important details and improve decision-making processes.

Enable the "Client Hold Rights" in Setup > Role > Maintenance Tab to allow users to set the new statuses (highlighted below).
