# 4.73.16 - Evaluation Previous Signature Comparison

We’ve introduced a new feature that allows evaluators, or any user reviewing loan documents in the Loan Menu, to compare a client’s most recent signature with the signature captured on their previous loan.&#x20;

This feature is built into the document evaluation process but can also be accessed directly from the Loan Menu > Documents option.

<figure><img src="../.gitbook/assets/image (457).png" alt=""><figcaption></figcaption></figure>

This comparison is presented side by side, making it easier for evaluators to spot any discrepancies and identify potential fraud.
