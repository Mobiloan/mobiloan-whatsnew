# 4.73.12 - Minimum Expense Values for Categories

We’ve added the ability to set **minimum expense values** for specific categories. These values will be required when:

* A client is filling out an **affordability expense disclosure**, or
* A client chooses to provide **detailed expenses**.

You can configure these minimum values in **Setup > Category > Affordability Tab**. Leave the field blank if you don’t want to enforce any minimum restrictions for a category.

This feature ensures that clients provide sufficient expense details, improving the accuracy of affordability assessments.
