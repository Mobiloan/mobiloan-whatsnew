# 4.73.13 - Setup - Additional New Loan Restrictions

We’ve introduced new checks to help you better manage new loan eligibility. Here’s what’s new:

**1. Maximum Active Loan Count**

If a category has a **`MAXIMUM ACTIVE LOAN COUNT`**&#x64;efined, the system will now verify whether the client exceeds this limit, including the loan about to be issued.&#x20;

**2. Maximum Overdue Instalment Count**

If a category has a **`MAXIMUM OVERDUE INSTALMENT COUNT`** defined, the system will calculate the total outstanding instalments across all overdue loans.&#x20;

You can configure these limits in **Setup > Category > Transaction Tab**.
