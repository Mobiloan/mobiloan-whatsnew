## Registered Mandate as a Repayment Method in Mobiloan

You can now configure **Registered Mandate (RMAN)** as a repayment method within Mobiloan.\
This opens up the ability for users to create **Promissory Notes** specifically tied to new RMAN mandate creations — providing a more seamless, reliable, and compliant debit order process.

**When setting up a new repayment method**, simply select **“Registered Mandate”** from the **Payment Stream** dropdown.

<figure><img src="../.gitbook/assets/image (468).png" alt="" width="375"><figcaption></figcaption></figure>

Once selected, an additional dropdown will appear, allowing you to configure the default debit order settings — including the **RMAN Mode** to be used when generating RMS Promissory Mandates.

The RMAN Mode options are:

* **RMAN Online** – Initiates the mandate creation process online, requiring an active internet connection.
* **RMAN Offline** – Triggers mandate creation via a bank-issued instruction, processed through the Allps system without the need for an internet connection.

## **Deprecated Role Updates**

The **“Create RMS Transaction”** role item has been **removed** from the **Debit Order Rights** section within the **Role Setup**.

This change reflects that **RMAN is now the primary mechanism** for mandate creation within the system.

### Wrap Up&#x20;

* **RMS Discontinuation**: The **Register Mandate Service (RMS)** will be discontinued from **10 March 2025**.
* **New Payment Stream**: A new stream, **Registered Mandate (RM)**, will replace RMS in the **National Payment System**.
* **Mandate Timing**: RM mandates can only be created **from 10 March 2025** onwards.
* **Migration**: All existing **RMS mandates** will be **migrated to RM** and processed under RM rules.
* **Simplified Process for Amplifin Clients**: Clients can create RM mandates/collections **without needing a failed DebiCheck attempt**.
* **Bank Compatibility**: RM works with **all EFT Debit-compatible accounts**.
* **Priority Presentation**: RM collections will be **presented before EFT Debits**.
* **Tracking Support**: RM includes **tracking**, starting from **12:00 each day**.
* **Real-Time Responses**: Settlements occur on the **same day**, with **near real-time responses**, similar to DebiCheck.
* **Account Types**: RM supports **juristic accounts** and those requiring **multiple signatories**.
* **Infrastructure**: RM uses the **same mandate infrastructure as DebiCheck**, though **collections are handled separately**.
* **Mandate Flexibility**: RM mandates can be **upgraded to DebiCheck**, and vice versa.
