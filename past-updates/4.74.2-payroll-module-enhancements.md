# 4.74.2 - Payroll Module Enhancements

We've been working hard to enhance our **Payroll Module**, and so far, we've introduced the following improvements to this sub-system within the app:<br>

**⚡Faster Loading with Asynchronous Processing:** Clients, employers, and loans are now loaded asynchronously, significantly improving system performance and reducing wait times. This ensures a more efficient and seamless experience.

A new **"Removed"** column has been introduced to indicate which items were removed. This data is now preserved in the actual batch receipt of the remittance for better tracking and transparency.
