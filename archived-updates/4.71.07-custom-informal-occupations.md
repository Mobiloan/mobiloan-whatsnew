# 4.71.07 - Custom Informal Occupations

Mobiloan now offers the flexibility to define custom occupation types for clients with informal income. This enhancement improves accuracy in affordability assessments.&#x20;

To learn more about creating and linking custom occupations, refer to the user guide.
