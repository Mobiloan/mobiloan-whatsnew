# 4.69.9 - Custom Reports and Report Based SMS's

We have successfully added the [**Report Based SMS templating**](https://docs.modalityapps.com/modules/reporting/report-based-smss) feature to the Reporting Module which allows users to send SMSs' using the report's results.

We have concurrently added a general **SMS template/ Placeholder** feature which has many other useful applications in Mobiloan.

We have added the [**Custom Reporting feature**](/broken/pages/ONJrkQU36EtE5afa09Zc) to the Reporting Module which allows users to design reports.
