# 4.71.02 -  Allps POS Receipts

### Manual Receipt Integration via Allps USB Terminal

Users can now create manual Point-of-Sale (POS) receipts directly through the Allps USB Terminal. Mobiloan will automatically allocate the corresponding funds to your AET account, mimicking the automatic receipting functionality of Allps Debi check.



Ensure that the user creating this receipt has the following **Transaction Rights** enabled for their **Role.**

These rights can be configured in **Setup >> Role > Transaction Step**
