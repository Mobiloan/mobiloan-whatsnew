# 4.69.24 Reporting Module - Manual  DB Synchronize

We've added the ability to manually synchronize the reporting database in real-time resulting in a more live version of the current standard reports.&#x20;

We've also included a "last synchronized" timestamp to inform you of the most recent data refresh. This way, you'll always be aware of the report's data freshness when you generate one.

Previously, users could only see data that was synchronized within the last hour. This meant that recent activity, such as new receipts or loan status changes, might not have been reflected in the reports.

To get the latest data, simply click the "sync" icon located below the standard reports table.
