# 4.69.17 - Copy Standard Reports and Creating New SQL reports under Custom Reports

We've added the option to copy an existing report from the standard table and save it  as  custom report whereby the user can then edit the sql and tweak accordingly.

Also, we've created the option to allow users to create their own reports using SQL and saving them as custom.
