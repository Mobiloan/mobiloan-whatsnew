# 4.71.06 - Collection Summary Feature

This tool provides a quick and easy way to analyze the distribution of collection tickets across different categories, making it even easer to recover any potential bad debt.

This feature enables users to select a grouping whereby you can instantly view the **total number of collection tickets for each group**.&#x20;

For example, selecting `Area` as a grouping will help you identify areas that require additional focus on your collection efforts.

For more information, select the **User Guide Link**&#x20;
