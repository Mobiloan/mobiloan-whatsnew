# 4.69.25 - CC Email Routing

Mobiloan now allows users to set up default CC email recipients for outgoing client documents like settlement letters, client statements, and third-party balance letters.

Once you configure a default CC email for any of these documents (settlement letters, client statements, or third-party balance letters), the CC field will automatically populate with the email address you set in the "Email Routing" section of your branch setup.

Simply add a default CC email address in the "Email Routing" section of your branch setup (see below for instructions). This ensures that a copy of each document is sent to your inbox alongside the client receiving it.
