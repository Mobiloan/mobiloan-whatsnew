# 4.69.16 - Automated Amplifin Diagnostics

We've added a feature which allows you to contact Amplifin Support upon every **Amplifin Error Message** presented to you whilst using Mobiloan, which allows you to reach out to Amplifin support directly through Mobiloan for speedy troubleshooting of Amplifin problems.

Selecting the 'Contact Amplifin Support' button will trigger an email with error logs included in the body of the email.

Skip the explanations! Technical details will be included in the email, which means Amplifin experts can immediately see the exact cause of the error, without you needing to explain technical details
