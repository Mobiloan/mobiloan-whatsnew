# 4.69.27 - Online Web App Configuration

In the past, setting up your online lending website involved making changes within the "Company Setup" section. This limited you to creating just one website per company and restricted the website's use to the entire company.

We've made some improvements! There's now a dedicated "Online Web App" menu within the setup menu. We've also unlinked companies from online web apps, allowing you to create multiple websites for different branches within your company.
